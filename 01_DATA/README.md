# Data directory

This directory contains inputs and lightweight data used for this project.

## Organization

- `genesets/` : GO, Hallmark, Reactome, SynGO and ageing-related signature inputs, where applicable.
- `markers/` : cell-subclass marker reference files used for annotation checks.
- `processed/` : derived donor metadata and processed data produced by the preprocessing notebook.

## Original data

The source dataset is the PsychAD HBCC snRNA-seq collection, available from [CZ CELLxGENE](https://cellxgene.cziscience.com/collections/84ce6837-548d-4a1f-919f-0bc0d9a3952f).

The original large `HBCC_Cohort.h5ad` file is not included in GitHub. Download the source dataset and place it at the location expected by `02_CODE/01_preprocessing.qmd` before reproducing the preprocessing workflow.

## Generated files not included in GitHub

Large processed files, including the following objects, may be omitted because of GitHub size limits:

- `processed/seurat_object_HBCC_224donors.rds` : sampled Seurat object for visualizations and cell communication.
- `processed/pseudobulk_HBCC_224donors.rds` : raw count data aggregated per donor and subclass for differential expression and ageing analyses.

These objects can be regenerated by running the preprocessing notebook and its supporting scripts, provided that the original data, software dependencies and enough storage/RAM are available.

Further outputs (including large network objects) may be omitted from `03_RESULTS/`, they are generated by the corresponding question-specific notebooks. Published HTML notebooks show the recorded results without requiring the complete computation again.

See the [project README](../README.md) for execution order, environment setup and project-wide limitations.
