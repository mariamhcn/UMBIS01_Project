# Results directory

This directory contains intermediate and final outputs generated by the Quarto notebooks in [`02_CODE/`](../02_CODE/).

Some large result files, particularly `.rds` objects, have **not been uploaded to GitHub due to their size**. These files are generated during preprocessing and downstream analyses and can be recreated by running the relevant notebooks, provided that the required input data and computing resources are available.

## Regenerating missing results

1. From the repository root, restore the R package environment with `renv::restore()`.
2. Ensure that the required input data are available in `01_DATA/` (including any large files not tracked by Git).
3. Run the corresponding `.qmd` notebooks in workflow order, starting with preprocessing if the necessary processed objects are missing.
4. Where a computationally intensive chunk is disabled with `#| eval: false`, change it to `#| eval: true` before rerunning the analysis; you can disable it again afterward to avoid unnecessary recomputation.

For example, in `05_Q4_cell_communication.qmd`, the CellChat and NeuronChat inference chunks must be enabled to regenerate their corresponding `.rds` results.

**Note:** Some analyses require substantial memory and execution time. Available HTML reports can be consulted without rebuilding all intermediate objects.
